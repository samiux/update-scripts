# USB/IP

USB/IP is now built-in in the Linux kernel (e.g. Ubuntu 26.04 HWE kernel 7.x).  It can share USB devices (such as printers, USB sticks, USB HDDs/SSDs and etc) over the internel network with no protection or encryption (WARNING : use with care).

Version : 0.0.1 (Stable Version) dated 2026-11-02 by Samiux (GPL-3.0)
